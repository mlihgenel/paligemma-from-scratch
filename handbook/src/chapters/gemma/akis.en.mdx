# The residual stream: a highway

<p className="lead">The key to understanding Gemma is a single variable: <code>hidden_states</code>. It is a <b>highway</b> that flows unbroken through all 18 layers. Each layer reads a copy from this road and adds an update on top.</p>

## The idea: layers do not replace the stream, they add to it

In a classic neural network every layer takes its input and puts something new in its place: <span className="mono">h ← f(h)</span>. With a residual connection the layer only computes a difference, and that difference is added to the stream:

$$
h \leftarrow h + f(\mathrm{norm}(h))
$$

This line has two important consequences.

- **The stream is never normalized.** `norm` only applies to the copy the branch sees. The stream itself can grow over the layers, and the final normalization happens once, in `self.norm` at the very end.
- **Every layer's input is independent of scale.** The `norm(h)` that `f` sees always has a similar size (RMS ≈ 1·(1+w)), however large the stream gets. That is what keeps the layers balanced.

## What breaks? Saving the residual after the norm

At first glance it looks harmless: two lines swap places, that's all. But the meaning of the highway changes completely.

## Pre-norm vs post-norm

The original Transformer (2017) used **post-norm**: add first, then normalize, <span className="mono">h ← norm(h + f(h))</span>. Gemma, Llama and SigLIP use **pre-norm**: <span className="mono">h ← h + f(norm(h))</span>.

<Fig caption={<><b>Three architectures, the same toy model.</b> With pre-norm the stream keeps carrying the embedding. Post-norm and the "residual after the norm" bug rescale the stream at every step.</>}>
<StreamCompare show={["normal", "residual_after_norm", "post_norm"]} />
</Fig>

<Callout kind="neden" title="Why did pre-norm win? The gradient path">
With pre-norm the output contains the input <i>itself</i>: <span className="mono">h_L = h_0 + Σ f_i(…)</span>. Taking the derivative gives <span className="mono">∂h_L/∂h_0 = I + …</span>. There is a straight "identity" path from the loss to the embedding that passes through no norm and no layer. In an 18-layer (or even 46-layer) model the gradient arrives through it without vanishing. With post-norm that path has to pass through a norm in every layer, which is why deep post-norm models are hard to train without learning-rate warmup.
</Callout>

<Predict q="The toy model on this page has a random Linear layer instead of self_attn. Why not the real GemmaAttention?" hint="What does the experiment measure?">
The experiments measure the behavior of the <b>stream</b>: where the norms sit, where the residual is saved, ×√d. For that, what the branch computes does not matter; the only requirement is that it writes an update to the stream. A random Linear whose scale (std 0.02) we control is the simplest version of that. Real attention plugs in with the same two lines (norm, branch, ⊕), and we look at it in <Link to="/gemma/attention">4.11</Link>.
</Predict>
