# Map of Gemma

<p className="lead">The first half of this part covers Gemma's pieces other than attention; the later pages cover attention and the KV cache. Before the details, let's see where every piece sits and where the model's weight is concentrated.</p>

Gemma's job in one sentence: take <S s="B, T" /> token ids and turn them into <S s="B, T, V" /> logits. In between, every token is carried as a <S s="D" /> vector through 18 layers. In PaliGemma, 256 of the input tokens come from the image.

## A token sequence's journey

Everything that happens to the tensor in one forward pass on the Gemma side. The rectangle's height is the sequence length T, its width the last axis (log scale).

<Scrolly label="Gemma forward, shapes" figure={(s) => <ShapeJourney step={s} />}>
<Step>**`input_ids`** <S s="1, 260" ax="B,T" />. 256 `<image>` placeholders (blue) and 4 text tokens (green). Only integers so far.</Step>
<Step>**`embed_tokens`**: each id picks a row of the table and the last axis becomes 2048. This is indexing, not math. The `<image>` positions go through the table too, but they will be overwritten shortly.</Step>
<Step>**Merge** (`paligemma.py`): the text embeddings are multiplied by √d = 45.25, and the features from the projector are written **unscaled** into the 256 image positions (purple). The shape does not change (<Link to="/gemma/sqrt-d">4.3</Link>).</Step>
<Step>**`GemmaModel` input**: the sequence arrives already scaled (`scale_embeddings=False`) and is not multiplied again. When Gemma is used on its own, this multiplication is the first thing `GemmaModel.forward` does.</Step>
<Step>**18 decoder layers**: each takes <S s="B, T, D" /> and returns <S s="B, T, D" />. The layers read from and write to the same stream (<Link to="/gemma/residual">4.2</Link>).</Step>
<Step>**Final norm**: the stream is normalized once (<Link to="/gemma/rmsnorm">4.4</Link>).</Step>
<Step>**lm_head**: the last axis widens from 2048 to **257216**, a score for every vocabulary token at every position. In float32, 260 × 257216 × 4 bytes ≈ 255 MB (<Link to="/gemma/tying">4.8</Link>).</Step>
</Scrolly>

<Callout kind="ozet">
The shape changes in only two places: at the input (id → vector) and at the output (vector → vocabulary scores). All 18 layers in between go from <S s="B, T, D" /> to <S s="B, T, D" />. That is no accident: every layer reads from and writes to the same **stream**. That is the topic of the next page.
</Callout>
