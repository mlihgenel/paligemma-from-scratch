## dtype ve eps tuzakları

| Tuzak | Sonuç | Bölüm |
|---|---|---|
| LayerNorm/RMSNorm eps'i PyTorch varsayılanı (1e-5) | küçük ama `allclose`'u bozan fark | <Link to="/encoder">3</Link>, <Link to="/gemma/rmsnorm">5.3</Link> |
| `F.gelu` (erf) yerine `approximate="tanh"` unutmak | ~5e-4'e kadar fark | <Link to="/gemma/geglu">5.4</Link> |
| ImageNet mean/std ile normalize | model soluk ya da parlak görür | <Link to="/goruntu">2</Link> |
| RMSNorm'u bf16'da hesaplamak | kare toplamında hassasiyet kaybı | <Link to="/gemma/rmsnorm">5.3</Link> |
| `type_as`'tan sonra `(1 + w)` ile çarpmak (Llama sırası) | elemanların ~%33'ünde 1 ulp fark | <Link to="/gemma/rmsnorm">5.3</Link> |
| normalizer'ı float32 ya da Python float ile kurmak | bf16'da ~%2.6 elemanda 1 ulp fark | <Link to="/gemma/sqrt-d">5.2</Link> |
| ÷√d · ×√d gidiş-dönüşü bf16'da | görsel token'larda ~%0.5'e kadar fark | <Link to="/gemma/sqrt-d">5.2</Link> |
| logit'leri bf16 bırakmak | 20 civarında 0.125 adım, olasılık %13'e kadar kayar | <Link to="/gemma/tying">5.7</Link> |
| `pixel_values`'u modelin dtype'ına çevirmemek | Conv2d dtype uyuşmazlığı hatası | <Link to="/hepsi">6</Link> |

## Sözlük

| Türkçe | İngilizce | Kısaca |
|---|---|---|
| yama | patch | 14 × 14 piksellik kare, bir görsel token'a dönüşür |
| akış | residual stream | katmanlar boyunca taşınan `hidden_states` |
| kapı | gate | GeGLU'da "ne kadar geçsin" yolu |
| ağırlık bağlama | weight tying | embedding tablosu = lm_head |
| yayma | broadcast | boyu 1 olan eksenin karşı boyuta kopyalanmış gibi davranması |
| ön ek | prefix | görüntü + prompt, tam attention |
| son ek | suffix | modelin ürettiği cevap, causal |
| ölçek | scale | √d, 1/√hd gibi çarpanlar |
| ulp | unit in the last place | bir sayı biçiminde iki komşu değer arası adım |
| sorgu / anahtar / değer | query / key / value | attention'ın üç projeksiyonu |
